# Badal Kalra Portfolio — Editorial Transition Build

This build is a custom HTML/CSS/JavaScript portfolio inspired by the editorial structure, large typography, project-led storytelling, and transition feel of the referenced Sanjay Menon portfolio on Wall of Portfolios, without copying its content or identity.

## Run locally

Open `index.html` in a browser, or use any static server.

Example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` — homepage
- `styles.css` — visual system, responsive layout, transitions
- `script.js` — theme switching, reveal transitions, progress line, magnetic interactions and page wipes
- `case-study-dashboard.html` — Birthday & Anniversary Dashboard case study
- `case-study-auto-assignment.html` — Automatic Work Assignment case study
- `case-study-jira.html` — JIRA dashboard case study
- `assets/badal-portrait.jpeg` — supplied portrait used in the hero

## Resume

Add your final website-specific résumé as `resume.pdf` in the project root so the résumé links work.

## Design notes

- Dark-first editorial/technical visual language
- Light mode toggle
- Staggered hero text reveal
- Page-wipe transition for case-study navigation
- Scroll reveal transitions
- Animated grid and marquee strip
- Subtle parallax on the hero image
- Magnetic buttons and hover spotlight on work cards
- Responsive desktop/mobile layout
- No public case-volume, CSAT, or enterprise-count metrics
